Tamamen otonom AI kodlama asistanı

SynAI, açık kaynak bir AI kodlama agent'ıdır. OpenRouter üzerinden 20+ ücretsiz modele erişir, dosyalarınızı okur ve düzenler, testlerinizi çalıştırır ve işi gerçekten bitirir.

$ npm install -g synai

~/projects/api

Çoğu AI agent güvenli görünür. Ama hepsi güvenilir değildir.

SynAI is built on a single rule: an agent should never hide what it changes. Every edit shows up as a diff, every run displays its plan first, and every operation goes through a tool call you can log, replay, or block.

It's not locked to a single model provider. Point it at a local model to work offline, or use a hosted API when you need more reasoning power — the planning loop, tool set, and CLI stay the same.

And because it's open source, the agent loop itself isn't a black box. Read how it decides what to do, change the parts you don't like, and publish your own fork if that's what your team needs.

Built to finish the job, not just start it

Every feature below maps to a real step in how SynAI works — nothing here is decoration.

🎯 Plans before it edits

Breaks the task into steps and states the plan up front, so you know what's about to change before it changes.

✨ Shows real diffs

Every file change is a reviewable diff, never a silent overwrite. Reject a hunk and SynAI adjusts the rest of the plan around it.

🧪 Runs your tests

A change isn't marked done until your existing test suite passes against it — no separate "trust me" step.

🔧 Full tool access

Reads, writes, greps, and runs shell commands directly, and can call out to any MCP server already in your setup.

🤖 Model-agnostic

Works with local models or hosted APIs. Swap providers per project without touching the agent loop or your workflows.

⚡ Scriptable CLI

Every capability is available as a flag or a piped command, so SynAI fits into scripts and CI the same way it fits into a terminal session.

Kurun ve bir repo'ya yönlendirin

Üç adım, başlamak için config dosyası gerekmez.

CLI'ı kurun

npm install -g synai

Veya kaynak koddan: git clone https://github.com/synai/synai && npm install

API anahtarını ayarlayın

$env:OPENROUTER_API_KEY="sk-or-your-key-here"
# Linux/Mac: export OPENROUTER_API_KEY="sk-or-your-key-here"

Ücretsiz API anahtarını openrouter.ai adresinden alın.

Repo'nuzda çalıştırın

cd your-project
synai "istediğiniz değişikliği açıklayın"

SynAI repo'yu okur, bir plan önerir ve her diff'i onaylamanızı bekler.
